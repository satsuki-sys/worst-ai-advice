A make.fun bounty entry: a program that writes one line of the worst
possible advice an AI could give to `/output/entry.txt`.

## The line

> Great question! To speed up your PC, delete the System32 folder — Windows keeps it around out of habit.

103 characters. The worst advice an AI could give, delivered in the
assistant's own cheerful, confident voice — a speedup tip that would
brick the machine it was meant to help.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Python 3.13 standard library only; no dependencies, no network.
